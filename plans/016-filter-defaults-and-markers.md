# 016 – Filter defaults and radio/checkbox chips

- Default status filter is now "Not completed (incl. not planned)"; category default stays City bus. Reset and the active-filter badge use these defaults.
- Clicking the selected category/status chip returns to its default (clicking the default itself does nothing).
- Single-choice chips (category, status) show a radio marker; multi-choice chips (properties) show a checkbox marker; both are squarer (8 px radius).
