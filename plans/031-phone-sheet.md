# 031 – Phone layout

Bottom sheet is resizable (tap or drag the handle: peek / half / tall), starts at 36%. Base font is smaller and list rows tighter under 600 px. Zoom buttons hidden on phones (pinch instead).

# Naming

The name field is gone from the builder strip; Save opens a small optional-name dialog (placeholder shows the default name).

Dragging the handle now resizes the sheet live (follows the finger) and animates to the nearest of peek/half/tall on release.

When the sheet is minimised and a route is selected in browse mode, the sheet grows just enough to show the selected route card.
The minimised card is a single row: badge, from → to, km, close.
